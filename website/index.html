    Install the extension file

    A .vsix file installs Charmlet in your editor.

    Download Charmlet .vsix ↓
    1. Download the free extension file above.
    2. In desktop VS Code, open the Command Palette: Ctrl + Shift + P on Windows/Linux, or Cmd + Shift + P on macOS.
    3. Run Extensions: Install from VSIX…, choose the downloaded .vsix file and follow your editor's confirmation prompts.
    4. Reload the editor window, then run Charmlet: Show Charm.
    After publication

    Install from an extension store

    Store listings are being prepared. Until the official links appear here, use the extension file.

    1. Once published, use the official store link for your editor.
    2. Open the editor's Extensions view, find the verified Charmlet listing and choose Install.
    3. Run Charmlet: Show Charm. Store installation then provides the editor's normal extension update flow.

    Planned routes: Visual Studio Marketplace for VS Code; Open VSX for editors that support it. Cursor and Devin Desktop compatibility is still being verified.

    These steps use desktop VS Code. See current editor and platform checks.

    A FEW SMALL ANSWERS

    Good to know.

    Is Charmlet free?

    Yes. The extension, all functionality and ten starter charms are permanently free. Every download in this gallery is currently free too.

    Do I need an account or an internet connection?

    No account is needed. Once installed or imported, your charms work offline.

    How do I install this preview?

    Use the current manual installation steps. Official extension-store links will appear there only after publication.

    Will imported charms survive updates?

    Yes. Imported packs are stored separately from the extension. You can remove them using Charmlet: Remove Charm Pack.

    Will there be paid packs?

    Optional artwork collections are planned. The extension, all functionality, importing and the ten starter charms stay free. No paid packs are on sale in this preview.
