# Try the free collection

This short trial checks whether the four charms are readable, easy to choose and comfortable beside normal editing. It is a prepared checklist; no trial feedback has been collected yet.

**On the Windows PC, in Microsoft VS Code:**

1. Run **Extensions: Install from VSIX...** and choose `extension/charmlet-0.1.0.vsix` from this repository.
2. Reload the window, then run **Charmlet: Show Charm**.
3. Open **Charm settings** and try **Terminal**, **Chip**, **Wafer** and **Circuit** in the Charm picker.
4. Choose your preferred size and resting cord length. Pull downward and release; it should return to that resting position.
5. Reload once to check the selected charm is remembered. Reset should keep the charm choice while restoring default size/cord.

| Feedback | What to record |
|---|---|
| Host | Windows and VS Code version |
| Favorite / least readable | Charm name and preferred size |
| Space | Does the dock leave enough room for normal editing? |
| Interaction | Any wrong return position, lost selection, focus issue or stuck drag? |
| Evidence | Short reproduction steps and a screenshot without private code |

Report feedback in [P2 #9](https://github.com/gautham-nvidia/charmlet/issues/9). Actual distribution and coworker participation are separate from this prepared checklist.
